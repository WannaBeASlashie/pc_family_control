# 家庭电脑管控系统 — 需求说明书

> 状态：讨论稿 v0.1　｜　更新：2026-10-20
> 参考对象：万象网管（上机/计费/锁屏模式），但目标是家庭儿童管控，非网吧计费。

---

## 1. 背景与目标

家庭局域网内有 **3 台 Windows 10 电脑**，主要供儿童使用，需要支持 **10 个账户**，另有一台常开的家庭服务器。

核心目标：

1. **万象式上机**：开机即锁屏，输入账号/卡号 + PIN 才能使用电脑
2. **统一计时**：时长按账号累计，跨 3 台机器共享额度（换机器不能续命）
3. **到点管控**：提醒 → 锁屏 → 强制下机
4. **家长远程控制**：锁定/解锁、加时、关机、发消息、查看状态
5. **正向激励**：通过完成任务获得积分/时长，积分可兑换上机时间

## 2. 范围

### 2.1 第一期做

- 账号/卡号体系（10 个孩子账户）
- 上机认证、会话计时、下机
- 每日时长额度 + 可用时段策略
- 到点提醒、锁屏、强制下机
- 家长 Web 管理端（跑在家庭服务器上）
- 远程控制（锁定、注销、关机、发消息）
- 加时申请 + 家长审批
- 任务/积分/兑换（基础版）
- 断网离线降级（缓存策略 + 补账）

### 2.2 明确不做（第一期）

- ❌ 网站/游戏**内容**过滤（已确认排除）
- ❌ 屏幕录像、键盘记录
- ❌ 公网访问（仅局域网）
- ❌ 手机原生 App（Web 端手机浏览器可访问即可）

## 3. 角色

| 角色 | 说明 |
|---|---|
| 孩子 | 受控账户，上机需认证，时长受限 |
| 家长 | 管理员，Web 端登录，管理一切 |
| 系统 | 服务端 + 各机服务，执行策略 |

## 4. 已确认的关键决策

| # | 决策 | 内容 | 影响 |
|---|---|---|---|
| D1 | **万象式应用级认证** | 共用一个 Windows 标准账户 + 自动登录，开机后由本系统锁屏，输入账号/卡号才放行 | 见 §12 风险 R1：Windows 层面不隔离，强制逻辑必须放在 SYSTEM 服务 |
| D2 | **时长按账号累计** | 额度挂在账号上，3 台机器共享；同一账号同时只允许一个活跃会话 | 计时以服务端为准 |
| D3 | **家庭服务器为中心** | API + 数据库 + Web 管理端部署在自有服务器；服务器宕机时客户端离线降级 | 需确认服务器 OS（§13 待定 Q1） |
| D4 | **强制层与表现层分离** | 计时/锁屏执行/看门狗在 SYSTEM 服务；锁屏只是 UI，可被替换 | 为二期升级 Kiosk/安全桌面（方案 C）留路 |
| D5 | **双账本** | 「分钟」和「积分」两种余额，所有增减都记流水，可审计 | 支持任务奖励、积分兑换、每日发放、消费、过期 |
| D6 | **审批通道插件化** | 加时/解锁的批准来源可扩展：家长 Web 审批、任务自动发放、应急解锁码、（预留）手机推送 | 接口统一为 request + grant |
| D7 | **管控强度分期** | 一期：应用级锁屏（B）；二期：Kiosk/安全桌面（C，用户倾向） | 见 §12 风险 R2：Win10 版本限制 |

## 5. 典型流程

### 5.1 开机 → 上机

```
开机 → 自动登录共享 Windows 账户（标准用户）
     → 本系统服务启动 → 全屏锁屏界面
     → 输入 卡号/账号 + PIN
     → 服务端校验：账户状态 / 余额 / 时段 / 是否已在别处上机
     → 通过：解锁桌面，开始计时
     → 拒绝：锁屏上显示原因（余额不足/时段未到/已被占用）
```

### 5.2 使用中

- 桌面角落常驻显示：当前账号、剩余时间
- 可随时点「下机」主动结束
- 服务端心跳同步余额与策略

### 5.3 到点处置（默认规则，待确认 Q5）

```
剩余 10 / 5 / 1 分钟 → 弹窗提醒
余额耗尽 → 锁屏 + 停止计费（保留会话，宽限 5 分钟）
宽限内家长可：加时 / 解锁 / 强制下机
宽限结束 → 强制注销（未保存内容丢失，需提前警告）
```

### 5.4 下机

- 主动下机：点「下机」→ 结束会话 → **注销**（推荐，见 Q6）→ 回到锁屏
- 切换账号：先注销当前会话，再让下一个孩子上机

### 5.5 申请加时

```
锁屏/托盘点「申请加时」（选 15/30 分钟 + 理由）
→ 服务端生成 request → 家长 Web 端看到待审批
→ 批准 → 客户端实时解锁并加时；拒绝 → 锁屏提示
```

### 5.6 任务与积分

```
家长发布任务（例：整理房间、阅读 30 分钟、完成作业）
→ 孩子在锁屏/托盘看到任务列表 → 标记完成（可附说明/拍照）
→ 家长确认 → 发放奖励（积分 和/或 分钟）
→ 积分可兑换：上机分钟、周末延长券等（家长配置兑换比例）
```

## 7. 非功能需求

| 类别 | 要求 |
|---|---|
| 可靠性 | 服务器宕机 ≠ 孩子完全不能用：客户端按缓存额度离线运行，恢复后对账 |
| 时间权威 | 一切计时以**服务端 UTC** 为准，客户端不参与计时决策 |
| 性能 | 心跳间隔 10s；解锁响应 < 1s |
| 安全 | 仅局域网；机器间 HMAC 签名 +（可选）自签 TLS；PIN 哈希存储 + 限速 |
| 部署 | 客户端一键安装脚本/MSI；服务端 Docker 或单二进制 |
| 数据 | SQLite 起步（单文件好备份），保留迁移到 PostgreSQL 的可能 |

## 8. 系统架构

```
                    ┌────────────────────────────┐
                    │      家庭服务器（常开）       │
                    │  API 服务 ─ Web 管理端 ─ WS  │
                    │        │                    │
                    │   数据库（SQLite/PG）         │
                    │   账本/策略/任务/审计          │
                    └─────────┬──────────────────┘
                              │ 局域网（HMAC 签名）
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
 ┌──────┴──────┐       ┌──────┴──────┐       ┌──────┴──────┐
 │   PC-1      │       │   PC-2      │       │   PC-3      │
 │ ┌─────────┐ │       │ ┌─────────┐ │       │ ┌─────────┐ │
 │ │SYSTEM 服务│ │       │ │SYSTEM 服务│ │       │ │SYSTEM 服务│ │
 │ │计时/守卫  │ │       │ │计时/守卫  │ │       │ │计时/守卫  │ │
 │ ├─────────┤ │       │ ├─────────┤ │       │ ├─────────┤ │
 │ │锁屏 UI   │ │       │ │锁屏 UI   │ │       │ │锁屏 UI   │ │
 │ │(会话内)   │ │       │ │(会话内)   │ │       │ │(会话内)   │ │
 │ ├─────────┤ │       │ ├─────────┤ │       │ ├─────────┤ │
 │ │本地缓存   │ │       │ │本地缓存   │ │       │ │本地缓存   │ │
 │ └─────────┘ │       └─────────────┘       └─────────────┘
 └─────────────┘
   家长用手机/电脑浏览器访问 Web 管理端
```

要点：

- **SYSTEM 服务**是执行主体：鉴权结果下发、锁屏指令、强制注销、看门狗（锁屏 UI 被杀 3 秒内重启）
- **锁屏 UI**（WPF）只是表现层，随时可替换成 Kiosk/安全桌面而不动业务逻辑
- **本地缓存**：当日策略 + 余额快照 + 离线会话流水（追加写），联网后补账

## 9. 数据模型（草案）

```sql
persons        账户：id, card_no, display_name, pin_hash, status, policy_id, created_at
machines       机器：id, name, mac, secret, last_seen, status
policies       策略：id, name, daily_minutes_weekday, daily_minutes_weekend,
               allowed_windows_json, max_session_minutes, break_minutes,
               idle_pause_minutes, curfew_json
sessions       会话：id, person_id, machine_id, started_at, ended_at,
               minutes_charged, end_reason, status
time_ledger    分钟账本：id, person_id, delta_seconds, kind
               (daily_grant/task_reward/parent_grant/redeem/consume/expire/refund),
               ref_type, ref_id, note, created_at, expires_at
points_ledger  积分账本：id, person_id, delta, kind, ref_id, created_at
tasks          任务：id, title, description, reward_points, reward_minutes,
               assignee_id, status(open/submitted/approved/rejected), proof,
               created_by, approved_by
requests       审批：id, person_id, machine_id, type(add_time/unlock),
               payload_json, status, decided_by, decided_at
audit_log      审计：id, ts, actor, action, target, detail_json
settings       配置：key, value
```

余额不存字段，由账本流水计算（可物化加速）。

## 10. API 草案

客户端（机器密钥 HMAC 签名）：

```
POST /api/v1/client/register          机器注册/换发密钥
POST /api/v1/client/heartbeat         心跳：上报状态，下发 指令/余额/策略
POST /api/v1/client/login             {card_no, pin} → 会话 + 余额
POST /api/v1/client/logout            结束会话
POST /api/v1/client/request           提交加时申请
GET  /api/v1/client/config            拉取策略/任务列表
```

家长端（登录会话）：

```
GET/POST/PUT/DELETE  /api/v1/admin/persons | policies | machines | tasks
GET  /api/v1/admin/overview            实时总览
POST /api/v1/admin/machines/{id}/command   lock/unlock/logoff/shutdown/reboot/message
POST /api/v1/admin/requests/{id}/decide    approve/reject
GET  /api/v1/admin/reports?from=&to=
WS   /ws                               实时推送给管理端与客户端
```

## 11. 安全设计

- 机器注册时分配 secret，请求带 HMAC(nonce + timestamp + body) 防重放
- PIN 用 Argon2id/PBKDF2 哈希，连续失败 5 次锁定 1 分钟
- 服务端绑定局域网网段，防火墙限制来源
- 家长 Web 端：密码登录（可选 TOTP）
- 离线补账流水带哈希链，服务端最终权威，冲突进审计

## 12. 风险与权衡

| # | 风险/权衡 | 说明 | 对策 |
|---|---|---|---|
| R1 | **共用 Windows 账户不隔离** | 10 个孩子的文件、浏览器配置、游戏存档全部共用；一个孩子的强制下机会影响整机会话 | 家庭场景可接受；如未来需要隔离，可给每人建 Windows 账户但保留万象锁屏（架构不变） |
| R2 | **Win10 真 Kiosk 受版本限制** | 多应用 Kiosk（Assigned Access）和 Shell Launcher v2 需要 Enterprise/Education；Pro/Home 不完整 | 二期走「服务替换 Shell + 安全桌面」自研路线（D4 已预留） |
| R3 | 应用级锁屏可被绕过 | 孩子若是管理员则一切失效 | 共享账户必须**标准用户** + SYSTEM 服务守卫 + 策略禁用任务管理器/改时间；物理层（BIOS 密码、禁 U 盘启动）另行处理 |
| R4 | 离线模式可能被利用 | 拔网线 → 用缓存额度 | 离线只放行当日基础额度（不含任务奖励），且流水不可篡改，恢复后对账 |
| R5 | 到点强制注销丢数据 | 未保存的游戏进度/文档 | 提前 10/5/1 分钟警告 + 宽限期，宽限内不注销 |
| R6 | Win10 已停止主流支持 | 2025-10 后无常规安全更新，内网使用风险可控，但新硬件/驱动兼容性下降 | 仅局域网 + 有限软件白名单可缓解 |
